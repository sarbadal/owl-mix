MMM Analysis Overview
=====================

The `analysis` submodule contains classes and functions for performing various 
analyses related to marketing mix modeling (MMM). This includes tools for 
analyzing model results, calculating metrics, and performing diagnostic checks.

Key Components
--------------

- **classifier.py**: Contains classes for classifying model results based on predefined criteria.
